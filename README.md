# Лабораторна робота 3

Тема лабораторної: Основи роботи з системою контролю версій Git  

Виконав: Маліборський Олександр

## Що зроблено в роботі:
- Створено локальний репозиторій
- Зроблоно коміти
- Відправлено файли на GitHub

## Основні команди

| Команда | Що робить |
| :--- | :--- |
| `git add` | Додає файли до індексу |
| `git push` | Відправляє зміни на сервер |
